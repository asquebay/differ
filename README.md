# differ
Консольная утилита, которая принимает от пользователя два текста и выводит разницу между ними в удобном для чтения виде.

В выводе к каждому изменению добавляются несколько строк контекста для улучшения читаемости.\
Содержимое выводится с чётким разделением по цветам:\
● удалённый текст подсвечивается красным цветом;\
● добавленный текст подсвечивается зелёным цветом;\
● контекст вокруг правок выводится приглушённым серым цветом.

Оба текста вводятся поочерёдно в интерактивном режиме терминала, текст можно редактировать перед отправкой. Отправка текста происходит нажатием любой из комбинаций клавиш: Ctrl+C, Ctrl+Z, Ctrl+D. В поле ввода в интерактивном режиме можно вставлять и редактировать тексты любого объёма.

## **Установка:**
```
git clone https://github.com/asquebay/differ.git && cd differ
```

## **Использование:**
```
go run main.go
```
